# 1 bis 10

Eine browserbasierte Kopfrechen-Reihe für Klasse 5 mit 40 festen, kontrollierbaren Durchgängen.

Jeder Durchgang enthält dieselben zehn Aufgabenklassen in wechselnden Darstellungen. Die Zeit jeder Aufgabe wird durch einen wachsenden Balken angezeigt. Am Ende folgt die gemeinsame Selbstkontrolle.

Die Anwendung besteht nur aus statischen Dateien und läuft über GitHub Pages. Nach dem ersten Laden funktioniert sie dank Service Worker auch offline.

## Bedienung

- Set auswählen und starten
- Leertaste: pausieren oder fortsetzen
- Pfeiltasten: vorherige oder nächste Aufgabe
- `F`: Vollbild
- Kontrollansicht: alle Aufgaben und Lösungen eines Sets prüfen oder drucken
